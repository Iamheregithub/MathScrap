# MathScrap 1.7.7.51

- Select and drag a rectangle to enclose whole strokes, lines and shapes; partially intersecting objects stay unselected.
- Tap a colour swatch to recolour selected ink and shape outlines. Select remains active and the selection is retained.
- The Select button now opens a colour-only tray using the existing mouse and tablet routing.
- Preserve ink geometry, opacity, individual original colours for Undo, and light/dark background colours. Preserve shape fill, transforms and uniform outline thickness.
- Treat each colour change as one Undo/Redo action; repeated identical colours and empty selections do not create undo entries.
- Leave ordinary SVG images, PDF backgrounds, covers and formulae unchanged.
- Update About and Windows installer versions to 1.7.7.51.

Validation added to native Windows suites: full containment with sidebar shown/hidden and multiple zoom levels, mixed Pen/Highlighter/solid/dashed Line recolouring, shape outline and fill preservation, toolbar colour routing, selection retention, single-step Undo/Redo, background changes, and save/reopen. Execution results are reported by the Windows workflow.
