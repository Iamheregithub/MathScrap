Welcome to GraphDesk

This file runs offline. Keep it on your computer and open it in your browser whenever you need a graph.

  1. Grid: Set the ranges and intervals, then press Draw graph or Enter.
  2. Plots: Add expressions and coordinate points. Press Enter after editing an expression.
  3. Style: Adjust labels, colours, image size, and layout.
  4. Export: Download a PNG or SVG, copy an image, or print the graph.

Expression notation

Use ^ for powers, * for multiplication (or write 2x), and parentheses for grouping. Supported functions: sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, sqrt, cbrt, abs, ln, log (base 10), exp, floor, ceil, round, min and max. Trigonometry uses radians. Constants: pi (or π) and e. Comparisons: =, <, <=, >, >=. Functions can be entered as x^2 or y=x^2.

For implicit curves such as circles, graphing and shading use a numerical mesh. Very small features may need a closer view. Number lines support expressions in x; the first coordinate in each point row supplies the position for horizontal and vertical number lines.

Save project downloads all settings, expressions, and points as a JSON file. Open restores it. Browser memory is convenient but can be cleared; project files are the dependable backup.

GraphDesk is an independent recreation of graphing features; it does not modify or activate HandyGraph. No registration key is needed.
