# Security policy

## Reporting a vulnerability

Please report suspected MathScrap security vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/Iamheregithub/MathScrap/security/advisories/new).

Include the MathScrap version, operating system, steps to reproduce, expected and actual behavior, and the potential impact. Use a minimal example with no student information, personal documents, passwords, or API keys.

Please do not disclose exploit details or credentials in public pull requests or other public discussions before the report has been assessed and a fix is available.

## Versions

Please use the latest MathScrap release. Reports affecting older releases are welcome, but fixes may be provided through a newer release rather than backported.

## Exposed credentials

If a credential has been exposed, revoke or rotate it with its provider promptly. Removing it from the latest source code does not remove it from repository history.
