# MathScrap security review — 2026-10-24

Reviewed the initial 71 CodeQL findings (59 high, 12 medium) on `master` and
`graphdesk-teaching-fork`. None of these initial findings were critical. The
findings are JavaScript issues, including repeated localized widget copies.
No CodeQL alert was dismissed just to reduce the count.

| Alerts | Assessment and change |
| --- | --- |
| 17–61 | Exercise text and hidden values were concatenated into HTML during edit/display or drop operations. Create nodes and assign `.text()`/`.val()` instead, across all five shipped language variants. |
| 15, 64 | QR-Code display and Notes dropdown labels are text, not markup. Use text nodes, including the selected Notes value. |
| 7–13 | GraphDesk already escapes user text in generated SVG. Its XML-to-HTML reparsing was unnecessary and brittle. Parse as SVG XML and import nodes for drawing, preview and printing. |
| 2 | Test-only metadata insertion was not a sanitizer or a runtime vulnerability. Build the XML metadata element directly instead of replacing a delimiter. |
| 1, 3 | ColorPicker's jQuery 1.3.2 copy had incomplete script removal and unsafe deep merging. Remove script nodes with a parser in selector-based `.load()`, reject `__proto__`, and avoid recursively merging inherited target objects. This is a focused patch, not an upgrade of all old jQuery copies. |
| 4, 16 | Spectrum's `appendTo` string should be a selector, not executable HTML. Select within `document`. Construct palette nodes directly, preserving color conversion and escaped tooltip values without serializing them back into HTML. |
| 14, 62, 63 | The HTML editor intentionally previews markup, but it must not execute in the editor's origin. Render previews in a sandbox without `allow-same-origin`. Construct editor wrapper IDs/classes with DOM attributes. |
| 5, 6, 65–69 | AnyEmbed and oEmbed intentionally accept markup. Render it in an opaque sandbox instead of appending it into the widget's privileged DOM. Construct media links/images as nodes and accept only explicit HTTP(S) attribute URLs. |
| 70, 71 | Build select options and optgroup labels using values/text/attributes, preventing option-label or value injection. |

## Scanner parsing warnings

The JavaScript log listed 29 HTML help templates with `.js` names. They are
loaded as text and rendered with Mustache; they are not executable JavaScript.
Rename them to `.html` and update all ten help loaders. Do not exclude their
directories or suppress the warning. Tests cover default, French, Slovak,
regional-language fallback and unsupported-language fallback.

## Validation and limits

`npm test` runs GraphDesk export/persistence/injection checks, 43 widget/library
DOM checks, and 50 help-template loads. `security-browser.cjs` separately checks
in Chromium that HTML preview, AnyEmbed and oEmbed retain formatted content and
script execution inside their sandbox while denying access to the parent DOM
and a parent `sankore` object. The Windows installer workflow runs these checks
before compiling, followed by native drawing, formula, recovery and OpenBoard
file-compatibility checks. CodeQL rescans both branches after the changes.

These checks do not establish that the entire inherited widget platform is
secure. Old vendor libraries and remote embedding services remain. In
particular, the standard no-build C++ scan does not cover all headers/generated
code; a successful scan is not an exhaustive audit. Browser sandbox tests model
the parent API boundary; they do not run Qt's actual WebChannel bridge.
